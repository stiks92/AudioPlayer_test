# Privacy nutrition label — карта для App Store Connect

Критик радара роста заметил: никто не связал обещание «no tracking» с формой
Privacy в ASC. Эта карта — все сетевые вызовы приложения и как их декларировать.
Заполняется владельцем в App Store Connect → App Privacy.

## Итог для формы

**Data Not Collected — почти.** Приложение не имеет своего бэкенда, аналитики
нет, рекламы нет, аккаунтов нет. Но два пункта требуют декларации:

| Декларация | Что | Почему |
|---|---|---|
| Data Not Linked to You → Usage Data → Listening history | Скробблинг ListenBrainz (opt-in) | Пользователь сам подключает свой токен; треки+время уходят на listenbrainz.org |
| Ничего | Всё остальное | См. таблицу вызовов — только контент-запросы без идентификаторов |

Если юристы Apple спросят про «User Content»: плейлисты/бэкапы никуда не
загружаются — файлы остаются у пользователя (share sheet), сервер приложения
отсутствует.

## Полная карта сетевых вызовов

| Хост | Когда | Что уходит | Идентификаторы |
|---|---|---|---|
| Пользовательские Subsonic/Navidrome серверы | Подключён сервер | Логин + соль-токен на ЕГО сервер | Только на сервер владельца учётки |
| Пользовательские WebDAV (Яндекс, Mail.ru, любой) | Подключено облако | Basic-auth на ЕГО облако | То же |
| api.audius.co + creator nodes | Поиск/стриминг Audius | Поисковые строки | Нет |
| api.deezer.com | Поиск (превью) | Поисковые строки | Нет |
| itunes.apple.com | Поиск (превью), подкаст-каталог | Поисковые строки | Нет |
| radio-browser.info зеркала | Каталог радио | Жанр/страна-фильтры | Нет |
| RSS-хосты подкастов | Подписка/эпизоды | GET фида | Нет |
| lrclib.net | Тексты песен | artist+title+duration трека | Нет (см. ниже) |
| listenbrainz.org | Скробблинг, только opt-in | Токен пользователя + история | Токен пользователя |
| Обложки (URL из ответов источников) | Отображение | GET картинки | Нет |

**LRCLIB-нюанс:** запрос текста раскрывает lrclib.net, ЧТО играет пользователь
(artist+title). Это контент-запрос без идентификатора устройства/пользователя,
как поиск — в форме ASC не декларируется как сбор, но фраза в маркетинге должна
быть «no tracking», не «нет сетевых запросов». Офлайн-кэш текстов сокращает
повторные запросы.

**Чего нет вообще:** аналитики/крашей SDK, рекламных SDK, fingerprinting,
push-серверов (уведомление понедельника — локальное), фоновых бэконов.

приложение разговаривает только с ними и с открытыми каталогами.»

servers and open catalogues."
